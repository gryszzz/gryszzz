### What I'm building

I work across reverse engineering, AI-agent infrastructure, program analysis, and practical software. I'm interested in systems that can **observe what is happening, test explanations, and retain the evidence behind their conclusions**.

Not everything here is production-ready. Some repositories are active research, some are developer tools, and some solve real-world problems.
